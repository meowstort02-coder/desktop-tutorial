# ИНСТРУКЦИЯ ПО СБОРКЕ (RU/EN)

1. Установите Android SDK и Gradle.
2. Поместите все файлы в одну папку.
3. Откройте терминал в корневой папке проекта.
4. Выполните команду: `./gradlew assembleDebug`
5. Готовый APK файл будет находиться в `app/build/outputs/apk/debug/`.
